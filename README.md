# Automata Mod

Adds clockwork robots and recharging stations to Minecraft

## Features

- Clockwork robot mob with a kinetic charge system
- Recharging stations for automata

## Requirements

- Minecraft 1.20.4
- NeoForge 20.4 or later
- Create mod 0.5.1.i or later

## Installation

1. Download the mod file
2. Place it in your mods folder
3. Launch Minecraft with NeoForge

## Usage

- Spawn automata entities in the world
- Use recharging stations to refill automata's kinetic charge

No additional configuration is required. The mod works out of the box.
